## What is PWF Auth?

A backend that gives your desktop and mobile apps everything they need to **sell
and protect software licenses** — all through one clean REST API with
AES-encrypted sessions.

- 🔑 **License keys** with HWID binding, expiry, and device limits
- 👤 **End-user accounts** — register / login / change password
- 🛡️ **Encrypted heartbeat sessions** + remote kill switch
- 🎁 **Free trials** & HWID-reset requests
- 🚀 **OTA update checks** (version + download URL)
- 📊 A dashboard for keys, customers, analytics, and threat intel

## 📦 Open-source example clients

Ready-to-run reference clients that exercise **every endpoint** — each mirrors the
